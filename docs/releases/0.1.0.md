The first stable release of Stubb, a Rust library for embedding coding agents in your application.

## Highlights

- **One API for four kinds of agent.** Claude Code, OpenAI Codex and Pi are driven through their native protocols, and any [Agent Client Protocol](https://agentclientprotocol.com) agent through `stubb::providers::acp`. Every provider implements the same `stubb::Provider` trait.
- **Sessions and streaming.** Start, resume, fork and list sessions, read stored history, and stream messages, tool activity and turn events.
- **Permission requests.** Forward an agent's tool permission prompts to your users and answer them asynchronously. Configure each provider's native approval and sandbox settings.
- **Agent controls.** Change model, effort and permissions mid-session, steer a running turn or queue follow-ups, send images, compact context, and follow subagents and background tasks.
- **Discovery.** Probe which agents are installed and signed in, show their name and logo, and update them with their own updaters, without starting a session.
- **Choose providers at compile time.** Each provider sits behind a Cargo feature (`claude`, `codex`, `pi`, `acp`), all enabled by default.

Stubb requires Rust 1.99 or newer and a Tokio runtime. See the [README](https://github.com/spelvia/stubb#readme) to get started and the [API reference](https://docs.rs/stubb) for every type.

## Compatibility

From this release, `0.1.x` versions only add to the API; breaking changes wait for `0.2.0`. Stored event JSON is versioned by `session::EVENT_FORMAT`. See the [versioning rules](https://github.com/spelvia/stubb/blob/main/CONTRIBUTING.md#versioning).

## Upgrading from a release candidate

- **From 0.1.0-rc.2:** no code changes. Update the version to `0.1.0`.
- **From 0.1.0-rc.1:** follow the [upgrade table in the 0.1.0-rc.2 notes](https://github.com/spelvia/stubb/releases/tag/v0.1.0-rc.2), then update the version.
