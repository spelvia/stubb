## Features

Stubb provides a shared Rust API for starting coding-agent sessions, streaming turn events, and checking which operations each provider supports.

- **Claude Code** connects through the CLI’s native streaming JSON protocol. Applications can opt in to receive and answer tool permission prompts. [#1](https://github.com/spelvia/stubb/issues/1)
- **OpenAI Codex** connects through the Codex app-server and exposes its native approval and sandbox settings. [#2](https://github.com/spelvia/stubb/issues/2)
- **Pi** connects through the CLI’s RPC interface. Applications can steer an active turn or queue a follow-up message. [#4](https://github.com/spelvia/stubb/issues/4)
- **Agent Client Protocol (ACP)** support lets applications configure an ACP v1 agent at runtime and connect over standard input and output.
