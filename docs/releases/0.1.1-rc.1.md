A release candidate for 0.1.1. It fixes how full Claude Code's context looks, reports context compaction from every provider, and lets Codex sessions read background task output.

## Fixes

- **Claude Code's context use is reported per model call.** `Usage.last` was the sum of every model call in the turn, so a long turn could report many times the context window. It is now the main agent's latest call, reported after each call instead of only at the end of the turn. The turn's sum only adds to `Usage.total`, and turns without a model call, such as `/compact`, no longer report zero usage.
- **ACP context size outside a turn** is reported as `Event::Usage` instead of `Event::Raw`.

## Features

- **Context compaction events.** The new `Event::Compaction` reports when an agent starts and finishes compacting its context, with `turn::Compaction`: its status, what started it, tokens before and after when the agent reports them, and an error when it failed.
  - Claude Code: start, end with tokens before and after, failure.
  - Codex: start and end of its `contextCompaction` item. It replaces the `Item::Other` items of kind `contextCompaction` in the live event stream; stored history still contains them.
  - Pi: start and end with tokens before and the estimated tokens after.
  - ACP: Stubb now advertises the `session.compaction` client capability and reports each `compaction_update` status change once.
- **Codex background task output.** `Session::task_output` reads a running Codex session's background commands, and `Provider::list_tasks` and `Provider::task_output` read them from stored sessions, as they already did for Claude Code.

## Compatibility

Only additions: `Event::Compaction` and the `turn::Compaction` types are new, and `Event` is `#[non_exhaustive]`. The event JSON format stays `EVENT_FORMAT` 1. `Usage.total` restarts when a session is resumed; for ACP agents it equals the current context size.
